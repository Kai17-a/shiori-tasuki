    MCPで接続する

    普段使うエージェントに task-tool を MCP サーバーとして登録し、会話で「#12をやって」と依頼します。AIの経過報告と結果を、この画面で確認できます。Claude Code では次のコマンドで登録します。

    task-tool mcp

    タスクを登録するだけでは実行されません。作業を始めるには会話で依頼してください。

    表示モード

    「システム」は OS の明暗の設定に合わせます。画面右上の月と太陽のボタンでも、ライトとダークを切り替えられます。選んだモードはこのブラウザに保存されます。

    背景画像

    画像だけを眺める

    PNG・JPEG・WebP・GIF・AVIF の画像を 5MB まで設定できます。画像はこのアプリのデータベースに保存されるので、どのブラウザで開いても同じ背景になります。

    0%で見えなくなり、100%で元の濃さになります。文字を読みやすくするため、20〜40%程度がおすすめです。

    現在の背景

    選んだ画像や設定は、保存する前からこの画面の背景で確かめられます。保存するまで、ほかのブラウザには反映されません。
